# OpenChamber × Token 用量

在 OpenChamber 右侧栏加一个 **Token 用量** 面板：按本会话、今天、近 7 天、近 30 天和历史累计统计 token 与费用。

- **本机数据**：只读 OpenCode 的本地 SQLite 数据库（默认 `~/.local/share/opencode/opencode.db`），不读取对话正文，不上传任何内容。
- **自定义单价**：每个模型可单独设置输入、输出、缓存读取、缓存写入单价（每百万 tokens）。
- **峰谷时段**：为模型设置谷时窗口（默认 00:30–08:30），窗口内使用另一组单价，按本机时区计算；也可以勾选周末、节假日全天按谷价。
- **长短上下文**：设置上下文阈值（如 200,000 tokens），超过后使用另一组单价。
- **手动余额**：按当前会话涉及的提供商分别填写余额；保存后会按该提供商之后的新增用量扣减，不自动获取余额。余额看板只显示各提供商的剩余余额。
- **子代理计入**：本会话统计包含它派生的子会话（子代理）。
- **一键清空历史**：只清空本扩展的统计起点，不删除 OpenCode 数据库；清空后可随时恢复完整历史。

## 安装

需要 OpenChamber 2.5 以上（Web 或桌面版）。

1. 打开 OpenChamber 的 **设置 → 扩展 → 从文件夹安装**，选择这个目录。
2. 安装后授予 **service（本地服务）** 权限。面板通过它以只读方式读取 OpenCode 数据库。
3. 在右侧栏打开 **Token 用量** 面板。

本地开发时：

```bash
npm install
npm run build   # 生成 panel/main.js 与 service/main.js
```

修改源码后重新 `npm run build`，在扩展设置里重新加载即可。

## 使用

**概览**：当前会话涉及的各提供商余额、历史消费，以及五个统计口径的费用与 token。费用右上角的 `*` 表示该口径里有还没定价的模型。图表是近 14 天的用量，鼠标放到柱子上会显示当天的 token 和费用；「按模型」卡片点标题可折叠/展开，状态会记住。

**余额**：点余额卡片里的「编辑」，只列出当前会话涉及的提供商；留空表示该提供商未设置，保存后每个提供商显示各自剩余余额（不计算总余额，也不在余额看板显示累计消费）。保存余额时会记录当时的消费作为扣减起点，之后该提供商的新增费用会从余额中扣掉；重新填写余额会以当前消费作为新的起点。提供商名称优先读取 OpenCode `opencode.json` 里的 `providers.<id>.name`，缺失时把 id 格式化成可读名称。

**清空历史**：概览底部的「清空历史统计」会把统计起点设为当前时间，五个统计口径从零开始；「恢复完整历史」会撤销这次清空。价格、余额和 OpenCode 数据库都不会被删除。

**价格**：先选货币，再给模型填单价。观察到的模型会自动列出来；没有价格的模型会在「待定价的模型」里给出快捷入口。未定价的模型费用按 0 计算，概览里会标 `*`。

每个模型有三层价格：

| 层 | 何时使用 |
| --- | --- |
| 基础价 | 默认 |
| 长上下文 | 单次请求的提示 token 超过设定阈值时 |
| 峰谷时段 | 调用发生在谷时窗口内、周末或填写的节假日时 |

峰谷与长上下文同时命中时，长上下文价格优先。节假日在勾选后按 `YYYY-MM-DD` 填写，多个日期用逗号分隔；只按本机时区的自然日判断，不自动识别法定节假日。

单价单位都是 **每百万 tokens**。费用是估算：

```
输入 × 输入价 + 输出 × 输出价 + 推理 × 输出价
+ 缓存读 × 缓存读价 + 缓存写 × 缓存写价
```

再除以 1,000,000。

## 数据口径

- 「今天」「近 7 天」「近 30 天」按本机时区的自然日计算；近 7 天含今天，近 30 天同理。
- 周末按本地自然日的周六、周日判断；节假日需要手动填写日期，不自动同步法定节假日安排。
- token 来自每条 assistant 消息的最终 usage；正在流式输出的那条消息要到本轮结束才会进入统计。
- 缓存命中率 = 缓存读 /（输入 + 缓存读）。
- 数据库只读打开，WAL 模式下不会影响 OpenCode 写入。
- 若 OpenCode 的数据目录不在默认位置，可在「价格 → 数据库路径」里填写完整路径。

## 限制

- 只统计本机 OpenCode 数据库；远程 OpenChamber 实例需要面板与数据库在同一台机器上。
- OpenCode 版本升级若改动数据库表结构，统计可能失效；面板会显示读取失败，不会写入或修改数据库。
- 费用是自己填的价格估算，不等于供应商账单。

## 开发

```
src/panel.js   面板源码（构建成 IIFE）
src/service.js 本地服务源码（构建成 CommonJS，Node 22+）
panel/         面板静态文件与构建产物
service/       服务构建产物
build.mjs      esbuild 构建脚本
```

单独调试服务：

```bash
OPENCHAMBER_SERVICE_PORT=5999 OPENCHAMBER_SERVICE_TOKEN=dev node service/main.js
curl -s -H 'Authorization: Bearer dev' -H 'content-type: application/json' \
  -d '{"sessionId":null,"timeZone":"Asia/Shanghai","prices":{"rules":[{"key":"*","input":1,"output":2,"cacheRead":0.1,"cacheWrite":1}]}}' \
  http://127.0.0.1:5999/stats
```
